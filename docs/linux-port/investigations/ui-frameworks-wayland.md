**Own host versus patch/upstream:** estimate **M, 2–4 person-weeks** for a sharp one-window input/list spike; **L/XL, 12–24+ weeks** for useful IME/clipboard/DND/window parity, longer for comprehensive accessibility/GPU/compositor coverage. An upstream host contribution offers the best long-term ownership.
