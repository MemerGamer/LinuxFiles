# LinuxFiles 0.1.0-alpha2

Second public alpha of LinuxFiles, an unofficial native Linux port of [Files](https://github.com/files-community/Files) by the Files Community. Expect rough edges and keep backups of anything you care about.

## Highlights

- Optional Adwaita-style appearance, background images that also show through Adwaita surfaces, and a window opacity setting.
- The glitching tab bar icon is fixed, and systems without GPU acceleration render with about half the CPU.
- A Nix flake for NixOS (`nix run github:MemerGamer/LinuxFiles`).
- Holding Page Down in big folders no longer freezes the window, and the Details header stays visible.
- Safer root helper installation and packaging filters.
- Everything from alpha1: native Linux (X11 / XWayland), fast grouped views, KDE service menus, optional polkit root actions, native file pickers, archives, tabs in a client-side title bar.

Full notes: [CHANGELOG.md](https://github.com/MemerGamer/LinuxFiles/blob/main/CHANGELOG.md).

## Install

Requires x86_64 Linux with X11 or XWayland. Packages are self-contained.

**Arch (AUR)**, which also installs the optional polkit root helper:

```sh
yay -S linuxfiles-bin    # or paru -S linuxfiles-bin
```

**AppImage**:

```sh
chmod +x Files-x86_64.AppImage && ./Files-x86_64.AppImage
```

**Flatpak bundle** (root actions are off in the sandbox):

```sh
flatpak install --user Files-x86_64.flatpak
flatpak run io.github.memergamer.LinuxFiles
```

**Nix** (flake, no root actions):

```sh
nix run github:MemerGamer/LinuxFiles
```

**Tarball**:

```sh
tar xzf files-linux-x64.tar.gz && ./linux-x64/Files
```

To install the tarball for your user, run `scripts/linux/install-local.sh --from <path to linux-x64>` from a clone of the repository. `files-packaging.tar.gz` is for packagers.

## Checksums

Download `SHA256SUMS` into the same folder as your download and run:

```sh
sha256sum -c --ignore-missing SHA256SUMS
```

## Known issues

- Text can look soft at 100 percent scale (Uno font hinting); with fractional scaling under XWayland set `Xft.dpi`.
- Window opacity needs a compositing window manager and fades the whole window.
- Light-theme toolbar buttons can fade when focused.
- The Grid context-menu acrylic can show an olive smear.
- The Properties dialog has no backdrop.
- Long file names wrap in Details.
- Wayland runs through XWayland.
- The Nix package has no root actions, and was built but not run on a real NixOS machine.
- The Windows build is not restored yet (phase 8).

Report problems at https://github.com/MemerGamer/LinuxFiles/issues.
