# LinuxFiles 0.1.0-alpha3

Third public alpha of LinuxFiles, an unofficial native Linux port of [Files](https://github.com/files-community/Files) by the Files Community. Expect rough edges and keep backups of anything you care about.

## Highlights

- Tags now persist across folder reloads and app restarts: Linux now loads each row's saved properties, which it never did before. Tag edits merge correctly with saved tags, and opening a zip no longer needs two Back presses to return to its folder ([#146](https://github.com/MemerGamer/LinuxFiles/pull/146)).
- Faster layout switches on Linux with a lightweight selection checkbox that avoids per-item animation overhead ([#145](https://github.com/MemerGamer/LinuxFiles/pull/145)).
- Experimental **Detect display scale from the compositor** setting in Settings > Appearance for sharper text on niri/xwayland-satellite when no display or toolkit scale is configured. Off by default; restart required. `UNO_DISPLAY_SCALE_OVERRIDE` also works and takes precedence. Some setups may double-scale ([#147](https://github.com/MemerGamer/LinuxFiles/pull/147)).
- New [pixelation diagnosis and workarounds](https://github.com/MemerGamer/LinuxFiles/blob/main/docs/linux-port/investigations/pixelation-findings.md) explain XWayland upscaling and Uno's font hinting limits ([#144](https://github.com/MemerGamer/LinuxFiles/pull/144)).
- Double-clicking a zip/tar/7z archive now browses inside it instead of opening another app. Extraction shows real byte progress and only opens the destination on success.
- Backdrop modes (Solid / Transparent / Blur) with separate background opacity, compositor-aware support and GTK/portal System colours. Blur requires KWin on X11; unsupported modes fall back to Solid.
- Cursor preferences are resolved from the environment, X resources or read-only GNOME settings; window chrome uses named themed cursors when available.
- Status Center icon sizing is corrected and the unsupported Uno progress ring is hidden on Linux, removing its red placeholder while retaining the operation-count badge.
- Open With loads on demand off the UI thread, application/service-menu parsing is cached, tag writes use an ordered background queue, and polling-backed listings refresh after app operations. Optional `FILES_TRACE=1` timing traces are documented in [performance tracing](https://github.com/MemerGamer/LinuxFiles/blob/main/docs/linux-port/performance-tracing.md).
- NixOS module with opt-in root actions (`programs.linuxfiles.rootActions`) and a runtime-capability assertion. The current alpha2 flake pin is rejected for this opt-in; alpha3 assets, updated hashes and the compatible-runtime marker are required in a follow-up update.
- Linux builds exclude unused Windows-only assets, packages and registry source generation. Windows paths remain in place; desktop runtime trimming and AOT remain disabled.

Full notes: [CHANGELOG.md](https://github.com/MemerGamer/LinuxFiles/blob/main/CHANGELOG.md).

## Install

Requires x86_64 Linux with X11 or XWayland. Packages are self-contained.

**Arch (AUR)**, which also installs the optional polkit root helper:

```sh
yay -S linuxfiles-bin    # or paru -S linuxfiles-bin
```

**AppImage**:

```sh
chmod +x Files-x86_64.AppImage && ./Files-x86_64.AppImage
```

**Flatpak bundle** (root actions are off in the sandbox):

```sh
flatpak install --user Files-x86_64.flatpak
flatpak run io.github.memergamer.LinuxFiles
```

**Nix** (flake, no root actions):

```sh
nix run github:MemerGamer/LinuxFiles
```

**Tarball**:

```sh
tar xzf files-linux-x64.tar.gz && ./linux-x64/Files
```

To install the tarball for your user, run `scripts/linux/install-local.sh --from <path to linux-x64>` from a clone of the repository. `files-packaging.tar.gz` is for packagers.

## Checksums

Download `SHA256SUMS` into the same folder as your download and run:

```sh
sha256sum -c --ignore-missing SHA256SUMS
```

## Known limits

- Still X11/XWayland only. On niri/xwayland-satellite, window opacity is disabled and backdrop modes fall back to Solid. Mica/Acrylic is not implemented on Linux.
- Some text/icons look soft on fractional-scale Wayland (XWayland upscaling). The experimental compositor scale setting or `UNO_DISPLAY_SCALE_OVERRIDE` can help; Uno font hinting at 100 percent scale remains a limitation.
- Select-all in folders with 10,000 items is still slow due to Uno selection handling.
- Successive tag edits on read-only tagged files can drop tags when extended-attribute writes fail ([#148](https://github.com/MemerGamer/LinuxFiles/issues/148)).
- Uno's content Arrow cursor mapping can still differ from the theme on some setups.
- Plain Nix installs, AppImage and Flatpak keep root actions disabled. The flake still pins alpha2 pending release assets and hashes; real NixOS authentication and packaged runtime checks remain pending.
- The Windows build is not restored yet (phase 8).

Report problems at https://github.com/MemerGamer/LinuxFiles/issues.
