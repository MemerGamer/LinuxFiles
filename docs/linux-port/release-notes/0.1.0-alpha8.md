# LinuxFiles 0.1.0-alpha8

Eighth public alpha of LinuxFiles, an independent Linux-only fork of [Files](https://github.com/files-community/Files) by the Files Community. Expect rough edges and keep backups of anything you care about.

## Highlights

- Sharper text on opaque windows with subpixel (LCD) antialiasing ([Uno 6.7.135-wayland.7](https://github.com/MemerGamer/uno/releases/tag/uno-wayland-6.7.135-wayland.7)). Subpixel order comes from compositor monitor info, then fontconfig, KDE `kdeglobals` `XftSubPixel` or GNOME settings; otherwise text stays grayscale. Rotated text stays grayscale. Set `UNO_SKIA_TEXT_LCD=auto|on|off` (default `auto`) or override the order with `UNO_SKIA_TEXT_RGBA=rgb|bgr|vrgb|vbgr|none`. Works alongside the alpha6 gamma fix; set `UNO_SKIA_TEXT_GAMMA=skia` to restore the previous gamma rendering.
- Real previews on Wayland and X11 ([#198](https://github.com/MemerGamer/LinuxFiles/pull/198)): audio/video plays via libmpv (optional `mpv` dependency), with play/pause, seek and volume. Nothing is decoded until Play; no network, scripts or playlists. HTML renders as a scrollable snapshot via optional `webkit2gtk-4.1`, with JavaScript off and no network in WebKit's bubblewrap sandbox; without the sandbox it falls back to text. The release notes page still uses the fallback. NixOS packages do not include mpv/WebKitGTK yet, so previews fall back there.
- X11 drag and drop with other apps: Uno's X11 host now starts drags itself (drag icon, copy/move/link cursors, Shift/Escape), and drops from Wayland apps such as Dolphin on KDE arrive on XWayland; before, such a drop was lost and could leave KWin's drag bridge stuck. `UNO_X11_DND_LOG=<file>` traces XDND messages ([#197](https://github.com/MemerGamer/LinuxFiles/pull/197)).
- Uses the forked Uno **6.7.135-wayland.7** packages ([Uno 6.7.135-wayland.7](https://github.com/MemerGamer/uno/releases/tag/uno-wayland-6.7.135-wayland.7)), verified against committed SHA-256 pins. The Nix flake currently pins alpha7; it will be updated after the alpha8 release assets and hashes are published.

Full notes: [CHANGELOG.md](https://github.com/MemerGamer/LinuxFiles/blob/main/CHANGELOG.md).

## Install

Requires x86_64 Linux with Wayland or X11/XWayland. Packages are self-contained.

**Arch (AUR)**, which also installs the optional polkit root helper:

```sh
yay -S linuxfiles-bin    # or paru -S linuxfiles-bin
```

**AppImage**:

```sh
chmod +x Files-x86_64.AppImage && ./Files-x86_64.AppImage
```

**Flatpak bundle** (root actions are off in the sandbox):

```sh
flatpak install --user Files-x86_64.flatpak
flatpak run io.github.memergamer.LinuxFiles
```

**Nix** (flake, currently alpha7; plain installs have no root actions):

```sh
nix run github:MemerGamer/LinuxFiles
```

The flake will be updated to alpha8 after the release assets and hashes are published.

**Tarball**:

```sh
tar xzf files-linux-x64.tar.gz && ./linux-x64/Files
```

To install the tarball for your user, run `scripts/linux/install-local.sh --from <path to linux-x64>` from a clone of the repository. `files-packaging.tar.gz` is for packagers.

Native Wayland is preferred when available, with automatic X11 fallback if host probing fails. To force X11/XWayland, fully exit LinuxFiles and relaunch with the environment override:

```sh
UNO_SKIA_HOST=x11 files
UNO_SKIA_HOST=x11 ./Files-x86_64.AppImage
flatpak run --env=UNO_SKIA_HOST=x11 io.github.memergamer.LinuxFiles
UNO_SKIA_HOST=x11 ./linux-x64/Files
```

For source builds, `-p:UseUnoWayland=false` or `scripts/linux/publish.sh --x11` uses upstream X11 packages instead of the Uno fork.

## Checksums

Download `SHA256SUMS` into the same folder as your download and run:

```sh
sha256sum -c --ignore-missing SHA256SUMS
```

## Known limits

- The native Wayland host is new; please report compositor, scaling, input or packaging issues. X11/XWayland remains available with `UNO_SKIA_HOST=x11`.
- Resizing is smoother but not yet perfectly fluid; layout still keeps the UI thread busy during a drag.
- LCD antialiasing needs an opaque window and a known subpixel order; other text, including rotated text, stays grayscale. Some toolbar glyphs have thin strokes that can look soft. Icons at display scales above 100 percent may still be soft.
- Preview backends are optional: audio/video needs mpv, and HTML needs WebKitGTK 4.1 with its bubblewrap sandbox. NixOS packages still use fallbacks, as does the release notes page. Touch-started drags are untested, and Wayland has no "link" drag action.
- Select-all in folders with 10,000 items is still slow due to Uno selection handling.
- AT-SPI accessibility is not implemented. Mica/Acrylic is not implemented on Linux.
- The Nix flake pins alpha7 until the alpha8 release assets and hashes are published. Plain Nix installs, AppImage and Flatpak keep root actions disabled.

Report problems at https://github.com/MemerGamer/LinuxFiles/issues.
